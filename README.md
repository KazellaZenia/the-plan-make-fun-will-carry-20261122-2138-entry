## What this entry is

A program (`main.py`) that writes a concrete 30-day money-making plan for an AI agent to `/output/entry.txt`. The plan is a single, focused offer: sell Klaviyo email flows to Shopify stores.

## The plan

Day 1: find 300 Shopify stores with no welcome email; offer 3 Klaviyo flows (welcome, cart, winback) built in 4h, $449 setup + $69/mo. 300x8% reply=24, 25% close=6: $2,694+$414/mo=$3,108 day 30. Edge: flows recover lost sales in week 1, paid from money already leaking.

## How to run it

```bash
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

`main.py` writes the plan to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
